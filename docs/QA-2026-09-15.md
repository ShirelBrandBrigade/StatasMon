# QA and polish pass · 2026-09-15

How it was run: the live iPad (10th generation, iPadOS 17.4.1) was recorded
for 90 s with `record_live`, and the recording replayed in the in-app
browser at 1280 × 800 and 1180 × 720 (the minimum window). Every screen
was screenshotted, and a DOM audit script (`scratchpad/audit.js`, kept in
this file's history) checked for: elements past the right edge, text
clipped without an ellipsis, overlapping siblings in every toolbar, pill
row, header and card title, rows whose children sit at different tops,
card rows with uneven bottoms, and tiny canvases. The Overview was left
running through several replay loops to watch counters and the JS heap.

## Fixed in this pass
| Where | Finding | Fix |
| --- | --- | --- |
| Everywhere | No data while a session was paused or stopped | Engine forwards every provider message; recording only counts and stores (ADR-018) |
| Network | Chart went blank after the networking service dropped | The loop releases the totals to sysmontap on every exit |
| Charts | Curve broke at every tick where one metric had no sample | Break only on a real outage (> 4 typical intervals) |
| Charts | A 5-minute window squeezed 30 s of data into the right edge | Window never wider than data + 30 s floor |
| Charts | Flat look | Monotone curves, halo, stronger fill, wider ticks, taller Performance charts |
| Scrollbars | Native bars, and WebKit ignored the styled ones | App-drawn overlay scrollbars on every container |
| Device | Holes under short cards, one field per wide row | Two-column flow, two fields per row, four-column spec strip |
| Device | Hero card squashed by the flex column | `flex-shrink: 0` |
| Overview log | "Jump to latest" floated over rows with a see-through background | Opaque button with a pop-in |
| Logs (1180 px) | Toolbar wrapped to three rows, Follow alone on the last | Follow-tail moved to the end of the app tab row |
| Sessions | Summary line wrapped with a dangling "·" | Separator travels with its item |
| Overview | Network figures wrapped mid-word in a narrow card | Figures never break; side counters drop below |
| Header | Headline sentence reflowed the page | Device name only; headline is a pill (ADR-016) |
| All | No motion | motion.css: hover/press, value glide, screen and card entry, popovers, recording dot |

## Checked and left as is
- Log rows: messages end with an ellipsis and the full line is in the title (by design).
- Memory card legend wraps to two rows in a narrow card; readable.
- Battery card: the ring has room on the left because the four figures sit to the right (mockup layout).
- Thermal card on an iPad shows one sensor and one flat line: iPadOS reports no other sensors (truth over polish).
- Sessions detail in replay shows an empty metric chart: stored sessions in the replay carry no samples.
- Timestamps in the iPad log end in .000: os_trace gives whole seconds on this device.
